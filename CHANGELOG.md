# Changelog

## 0.1.1 (2026-11-12)

First Marketplace release.

- Free: Format Document and Format Selection that change only whitespace between tags, Minify XML, XPath 1.0 with the file's namespaces and clickable results, Copy XPath at Cursor in 3 styles, an XML Tree view that follows the cursor, well-formedness checks, entity bomb and external entity warnings, and Format Large XML File on Disk.
- Zovo Pro (USD 19 once, every Zovo extension), 3 free tries per tool on this computer: Run XPath on every XML file in a folder (results as CSV, JSON or a Markdown report), Format all XML files in a folder (or a report of what would change), and Compare two XML files ignoring formatting and attribute order. A try counts only when the tool gives a result.
- The Pro tools are in the Command Palette, in the Explorer right-click menu ("Zovo Pro: ..." on folders and XML files) and as one line at the end of XPath Results. The setting `xmlXpathTools.showProTools` hides the menu entries and that line. Nothing about Pro shows when you open a file.
- "More free tools" starts with the Zovo extensions most related to this one; a pick opens its Marketplace page. The walkthrough ends with a step that links them. Nothing installs on its own.
- Rating: one ask after 2 files worked at least 30 minutes apart, never in the first 2 minutes of a window and never after an error. The setting `xmlXpathTools.askForRating` turns it off.
